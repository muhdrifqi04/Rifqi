# Ruang Tarannum

Website pembelajaran, katalog bacaan dan latihan tarannum dalam Bahasa Melayu.

## Jalankan secara setempat

Buka `index.html` dalam pelayar. Untuk menggunakan rakaman mikrofon, jalankan melalui `localhost` atau laman HTTPS dan benarkan akses mikrofon.

## Fungsi

- Pengenalan lima maqam: Bayati, Hijaz, Nahawand, Rast dan Soba.
- Ruang dengar dengan contoh bacaan audio.
- Latihan rakaman suara terus dalam pelayar; audio kekal pada peranti pengguna.
- Reka bentuk responsif untuk telefon dan komputer.

Audio bacaan dimuatkan dari EveryAyah; sambungan internet diperlukan untuk main balik.
